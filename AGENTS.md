# Agents

## Commits

Use [Conventional Commits](https://www.conventionalcommits.org/): `<type>(<scope>): <subject>`,
with the scope optional. The types in use are `feat`, `fix`, `test`, `ci`, `chore`, `style`,
`refactor` and `docs`. For example:

- `fix(zone_sync): thaw zones when the sync is killed`
- `ci: one workflow for tests, prek and the deploy to sega`
